# Louvre 0.5 content

Five level files built from the playbook doc (https://claude.ai/code/artifact/ff9f143f-3ac4-458a-8037-1c68ebbee5a8), in the PRODUCT.md JSON format and the filenames from 0.5-plan.md. Owned by the "English Louvre storyplot playbook" thread; the app thread copies them into the repo's content/ folder.

- Each file: 1 lesson, at least 3 questions (flexible per work since 2026-10-15; the first eight levels have 5) within the time budget, start "n1", the last story node (n6, n6b or n6c) has no "next" (end of level).
- Checked: every "next" exists, every node reachable, sources non-empty, word budgets (story 45, branch 40, question 15).
- imageCredit (2026-10-09): verified on each photo's Wikimedia Commons page. Paintings are public-domain reproductions; the two sculpture photos are CC0 (Venus de Milo by Shonagon, Winged Victory by Wilfredor).
- 2026-10-09: added optional fields (backward compatible, nothing removed or renamed): `artwork.medium`, `artwork.dimensions`, `artwork.museumUrl` for the museum label; top-level `speakers`; `lessons[].narrator`; and a `voice` object on some story/branch nodes (`speaker`, `kind` "imagined" or "quote", `text`, plus `cite` and `source` for quotes). See PRODUCT.md "Data format". Narrators: Leonardo, the Venus de Milo itself, the Winged Victory itself, Delacroix, Géricault.
- 2026-10-09 (content depth): all five levels revised to the PRODUCT.md "Depth standard" (levels 2–5 rewritten, Mona Lisa lighter pass). Added the optional branch field `correction` ({ `kind`, `verdict`, `tempting`, `truth`, `evidence` }) on every wrong-answer branch; extra story screens between questions use ids like `n3b`. Question, merge-line and branch ids from the earlier version are kept, so saved mid-level places still resolve.
- 2026-10-09 (Close-Up Challenge): `content/challenge/NN-name.json`, one round per artwork in the PRODUCT.md "Challenge files" format, with the review audit trail (sources, quotes, quote and crop checks) per question. Crops live in `public/images/challenge/<artwork>/`; their boxes are the `zoom` fractions of the full-resolution Commons file named in `zoomImage`. `npm run check-content` checks both kinds of file and prints each round's reading time.
- 2026-10-13 (0.6 catalogue): `content/modules.json`, the catalogue in the PRODUCT.md "Catalogue file" format: 3 wings, 15 modules and the "Beyond the 15" appendix, 100 works (93 + 7). Generated once from the project files `catalogue/modules.csv` (verified rows only; `catalogue/module-candidates.csv` is not used) with each off-view work's `displayNote` taken from `catalogue/top-100.csv`; edit this file by hand from now on. Work ids are slugs of the English title without a leading "the"; the five works with a level keep their level file's `artwork.id` and link it with `levelId`. Works are in module order (on view by room number, then on view without a room number, then not on view), so The Disembarkation of Marie de' Medici (room 801, Galerie Médicis closed) is listed last in module 12, not first as in the CSV. Module 11, Spanish Painting, has no works and status `rooms-closed`. `npm run check-content` checks the file and prints its counts. No page reads it yet.
- 2026-10-13 (label sheet): every work in `content/modules.json` gained `medium` (the record's materials and technique, in English) and, where the record gives one, `titleFr` (the record's own French title), taken from `catalogue/top-100.csv`. The five works with a level use their level file's `artwork.medium`. 27 rows across all departments were spot-checked against their collections.louvre.fr records (louvre.fr's Gallery of Five Continents page for the three works without one); five media and two French titles were corrected to the records' wording (Jewel Coffer of Louis XIV, Crown of Louis XV, Eleanor of Aquitaine's Vase, Portrait of Isabella d'Este, Marquise de Pompadour; the Lamassu relief, Hunts of Maximilian: December, and the full Tomb of Philippe Pot title). The three Gallery of Five Continents works have no French record, so they carry no `titleFr`. A medium the records don't confirm is written "TBD".

- 2026-10-15 (flexible question counts): the number of questions is flexible per work. A level needs at least 3 questions (no fixed 5) and must fit the time budget: about 5 minutes, never more than 7 on the slowest path. A close-up round's `roundSize` may be 1 to 4 (no fixed 2), with a pool at least that long; a work's level plus its heaviest close-up play must fit 10 minutes, and the trail's five rounds 12. Both the build and `npm run check-content` enforce the time caps. Existing files are unchanged (5 questions a level, rounds of 2).
